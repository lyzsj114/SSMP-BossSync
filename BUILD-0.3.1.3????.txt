SSMP 0.3.1.3 修复内容
======================

在 0.3.1.2 基础上增加：

1. SceneHostPolicy：scene host 只在空场景、缺失房主、原房主离开或断线时变更。
   死亡与普通重进不再触发 host 交接。
2. FsmActionHooks：实体构造期间抑制 SetParent FSM 动作，作用域支持嵌套并保证
   构造结束后恢复。
3. SaveDataMapping：关闭 FisherWalkerIdleTimeLeft 和 FisherWalkerTimer 的同步。
4. SSMP 与 SSMPServer 版本统一为 0.3.1.3。
5. 新增 BossSyncRegression，自动回归从 73 项增加到 82 项。

验证：
- dotnet build SSMP.sln -c Release
- dotnet run --project SSMP.SaveSync.Tests -c Release
- 独立服务器启动与正常关闭
